# Anime Converter

Конвертер аниме-файлов на базе `ffmpeg`/`ffprobe`.

Проект автоматически обрабатывает видео из:

```text
/home/chaser/data/jormungandr/transmission/complete
```

и сохраняет результат в:

```text
/home/chaser/data/jormungandr/ongoing
```

При обработке сохраняется структура каталогов.

## Версия

**v0.0.2**

### Изменения v0.0.2

* исправлена блокировка одновременного запуска через `fcntl.flock`;
* второй экземпляр конвертера корректно завершается;
* усилена защита поиска внешних аудио/субтитров от совпадений с соседними аниме;
* поиск внешних дорожек ограничен каталогом видео и разрешёнными специальными каталогами;
* сохранено сопоставление по имени, серии, языку и другим признакам;
* отключено увеличение видео `480p` до `720p`;
* видео выше `720p` уменьшается до `720p`;
* видео `720p` и ниже сохраняет исходное разрешение;
* сохраняется соотношение сторон и обеспечивается чётная ширина;
* добавлен безопасный режим `--dry-run`;
* исходный файл удаляется только после успешной конвертации и проверки результата через `ffprobe`;
* при ошибке `ffmpeg`, `ffprobe` или некорректном результате исходный файл сохраняется.

## Требования

Необходимы:

* Python 3
* `ffmpeg`
* `ffprobe`
* systemd — для запуска как daemon

Проверка:

```bash
python3 --version
ffmpeg -version
ffprobe -version
systemctl --version
```

## Структура каталогов

Основные каталоги:

```text
/home/chaser/data/jormungandr/
├── transmission/
│   └── complete/
└── ongoing/
```

Конвертер сохраняет структуру каталогов относительно `transmission/complete`.

## Установка

Перейти в каталог проекта:

```bash
cd /path/to/anime-converter
```

Запустить установочный скрипт:

```bash
chmod +x install.sh
sudo ./install.sh
```

После установки проверить unit:

```bash
systemctl status anime-converter.service
```

Если unit устанавливается под другим именем, используйте имя, указанное в `anime-converter.service`.

## Запуск через systemd

Запустить:

```bash
sudo systemctl start anime-converter.service
```

Включить автоматический запуск при загрузке:

```bash
sudo systemctl enable anime-converter.service
```

Перезапустить:

```bash
sudo systemctl restart anime-converter.service
```

Остановить:

```bash
sudo systemctl stop anime-converter.service
```

Проверить состояние:

```bash
systemctl status anime-converter.service
```

Посмотреть журнал:

```bash
journalctl -u anime-converter.service
```

Следить за журналом в реальном времени:

```bash
journalctl -u anime-converter.service -f
```

## Ручной запуск

Для обычного запуска:

```bash
python3 anime-converter.py
```

При ручном запуске используется та же блокировка `fcntl.flock`, поэтому запуск второго экземпляра одновременно с работающим daemon не должен приводить к параллельной обработке.

## Dry-run

Для проверки обнаружения файлов без запуска `ffmpeg`:

```bash
python3 anime-converter.py --dry-run
```

`--dry-run` выполняет один проход по входному каталогу и показывает:

* найденные видео;
* найденные внутренние и внешние аудио;
* найденные субтитры;
* планируемый выходной файл;
* планируемую команду `ffmpeg`.

При этом файлы не конвертируются, не перемещаются и не удаляются.

## Проверка синтаксиса

Перед запуском:

```bash
python3 -m py_compile anime-converter.py
```

Проверить без создания `.pyc`:

```bash
python3 -m compileall -q anime-converter.py
```

## Проверка systemd unit

Проверить синтаксис unit:

```bash
systemd-analyze verify anime-converter.service
```

Если unit уже установлен:

```bash
systemd-analyze verify /etc/systemd/system/anime-converter.service
```

После изменения unit:

```bash
sudo systemctl daemon-reload
sudo systemctl restart anime-converter.service
```

## Проверка блокировки

Проверить, что daemon уже запущен:

```bash
systemctl status anime-converter.service
```

Затем попытаться запустить второй экземпляр:

```bash
python3 anime-converter.py
```

Второй процесс должен завершиться без запуска второй обработки.

Блокировка основана на `fcntl.flock`, а не на наличии lock-файла.

## Проверка безопасной обработки

При успешной обработке порядок следующий:

```text
исходный файл
      ↓
ffmpeg → временный файл
      ↓
ffprobe
      ↓
проверка результата
      ↓
атомарное перемещение в итоговый файл
      ↓
удаление исходника
```

Если `ffmpeg` завершился с ошибкой или результат не прошёл проверку, исходный файл не удаляется.

## Проверка разрешения

Правила масштабирования:

| Исходное видео | Результат |
| -------------- | --------- |
| 480p           | 480p      |
| 576p           | 576p      |
| 720p           | 720p      |
| 1080p          | 720p      |
| 1440p          | 720p      |
| 2160p          | 720p      |

Соотношение сторон сохраняется.

Видео с высотой `<= 720` не увеличивается искусственно.

## Поддерживаемые дорожки

Приоритет языков:

```text
RU → JP → EN
```

Поддерживаются:

* внутренние аудиодорожки;
* внешние аудиофайлы;
* внутренние субтитры;
* внешние субтитры.

Внешние дорожки сопоставляются с видео только при достаточной уверенности.

Специальные каталоги для внешних дорожек:

```text
audio
audios
sound
voices
dub
озвучка
аудио
sub
subs
subtitle
subtitles
субтитры
```

Родительские каталоги соседних релизов автоматически не используются для поиска дорожек.

## Формат результата

Видео:

```text
H.264
MKV
```

Аудио:

```text
MP3
192 kbit/s
```

Субтитры копируются без перекодирования, если это поддерживается выбранной конфигурацией.

Метаданные и главы сохраняются.

## Что происходит при сбое

Исходный файл должен оставаться на месте, если:

* `ffmpeg` завершился с ошибкой;
* `ffprobe` не смог проверить результат;
* отсутствует видеопоток;
* получен неправильный видеокодек;
* получено некорректное разрешение;
* результат повреждён;
* исходный файл исчез во время обработки;
* внешняя дорожка стала недоступна;
* NFS временно недоступен.

Временный результат не считается готовым файлом до успешной проверки.

## Версия v0.0.2

Основная цель версии `v0.0.2` — сделать обработку безопаснее:

* исключить параллельную обработку;
* не подбирать дорожки от соседнего аниме;
* не делать ненужный upscale;
* не удалять исходник до полной проверки результата;
* добавить безопасный режим предварительного просмотра.
